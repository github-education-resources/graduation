# GitHub Graduation 2020

GitHub Education hosted the 2020 virtual graduation event. This repository
preserves a brief historical description and the event's
[Code of Conduct](CODE_OF_CONDUCT.md).

## Collection closed

We no longer accept participant submissions. Do not submit personal information,
photos, profile links, or other identifying content in files, issues, or pull
requests.

## Current-file cleanup and limits

This cleanup removes participant records, identifying file paths, all repository
images, and the yearbook exporter from the proposed tracked tree. It also removes
the exporter's npm scripts and dependencies. We retain no replacement records,
avatars, identity mappings, or generated participant datasets.

The cleanup reaches the default branch only after maintainers merge the cleanup
pull request. It does not erase prior disclosures or rewrite Git history.
Personal information may remain in old commits, commit author metadata, pull
request deletion diffs and file lists, historical raw URLs, other branches and
tags, forks, discussions, releases, platform contributor metadata, caches, and
external yearbooks or other hosted services. This change does not modify those
surfaces.

For general assistance, contact [GitHub Support](https://support.github.com/).
